### Publishing

For publishing the webpage, I use GitHub Pages. There are different ways to publish 
a webpage using GitHub Pages (see https://quarto.org/docs/publishing/github-pages.html).
I use the `quarto publish gh-pages` command. 
After making your changes, simply commit and push them to the main (or master) branch.
Then, while on the main/master branch and in the repository’s root directory, 
run the `quarto publish gh-pages` command in the terminal.
